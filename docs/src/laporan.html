01 · Ringkasan Proyek

Apa itu Nalar Nusantara?

Nalar Nusantara adalah aplikasi kuis pilihan ganda bertema pengetahuan umum Indonesia. Pengguna memasukkan nama, memilih kategori soal (Budaya, Sejarah, Sains, Teknologi, Geografi), lalu mengerjakan kuis 12 soal — dengan atau tanpa batas waktu 20 detik per soal. Di akhir kuis, pengguna melihat skor, predikat pemahaman, statistik lengkap, rekor pribadi, serta pembahasan setiap soal.

Aplikasi dibangun tanpa database — bank soal dummy tersimpan lokal di dalam kode. Desain memakai bahasa visual neo-editorial “bone & ink”: latar krem tulang, tinta gelap pekat, aksen jingga, kartu bertepi tebal dengan bayangan padat tanpa blur, serta tipografi display Syne dan teks Space Grotesk.

State Management — Provider di atas MaterialApp

Empat ChangeNotifier diregistrasi lewat MultiProvider pada akar aplikasi, sehingga progres kuis tidak pernah hilang akibat rotasi layar atau perpindahan halaman:

// lib/main.dart
MultiProvider(
  providers: [
    ChangeNotifierProvider(create: (_) => ThemeController()),  // tema terang/gelap
    ChangeNotifierProvider(create: (_) => QuizController()),  // progres, skor, timer, streak
    ChangeNotifierProvider(create: (_) => ScoreStore()),      // rekor & riwayat skor
    ChangeNotifierProvider(create: (_) => PrefsStore()),      // preferensi timer & acak
  ],
  child: const _AppShell(),
)
